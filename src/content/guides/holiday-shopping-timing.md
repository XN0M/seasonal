## Plan before you purchase

Start a list of recipients and a budget for each. Save ideas early without assuming you need to order everything immediately.

## Check the return window

Count from the retailer’s stated start date, not the day the gift will be opened. If a gift might need a different size, favour a window that covers the occasion.

## Order timing depends on the gift

Personalised items, international delivery and made-to-order goods often need more planning. Use the merchant’s actual estimate rather than a generic countdown.

## Set a backup you would still be happy to give

If delivery cannot be confirmed, consider a locally available alternative or a shared experience. This is a planning idea, not a claim about any retailer’s delivery performance.
